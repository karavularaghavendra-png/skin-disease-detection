# 🔬 Skin Disease Detection Using Deep Learning

Upload a skin image and get an **instant AI-powered diagnosis** with confidence scores, severity levels, and medical recommendations.

## Features
- 🧠 **MobileNetV2** deep learning model
- 🎯 **Test-Time Augmentation (TTA)** for reliable predictions
- 🛡️ **OOD Detection** — rejects non-skin images automatically
- 📊 **Confidence scoring** with reliability analysis
- 💊 **Medical recommendations** for each detected condition

## Usage
1. Visit the web UI at the app URL above
2. Upload a clear, close-up photo of human skin
3. Get instant diagnosis with confidence score

## Supported Conditions
- Acne, Eczema, Psoriasis, Melanoma, Rosacea, Ringworm, and more

## Disclaimer
⚠️ This is an AI-assisted screening tool only. Always consult a qualified dermatologist for medical advice.
